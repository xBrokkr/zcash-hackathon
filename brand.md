# Brand: ShadeCheck

Status: active

ShadeCheck is monochrome-first. The visual system uses near-black surfaces, neutral grays, white text, and one restrained inverted action state. Semantic findings use structure, labels, borders, and icon shape before color.

## UI contract

- Dark theme first.
- Monochrome palette. No glow, gradients, neon, or decorative color wash.
- Inter for UI text. A system monospace is reserved for protocol strings.
- Maximum font size: 36px.
- Maximum font weight: semibold.
- Shared radius: 16px.
- One-pixel borders. Separation uses borders or surface contrast, not stacked effects.
- All findings remain understandable without color.

## Voice

Precise, calm, and operational. Say what was checked, what was not checked, and what the builder should do next.
